# Portfolio CLI

##  Portfolio CLI  is a lightweight command-line tool that provides **My Portfolio** directly in your terminal.

## Installation

### 1. Download the Binary

Go to the [Releases](https://github.com/EbraamSobhy/Portfolio-CLI/releases/tag/v1.0.0) page and download the binary for your operating system.

### 2. Install (Linux / macOS)

Make the binary executable:

```bash
chmod +x portfolio-cli-linux

# Move it to a directory in your PATH:
sudo mv portfolio-cli-linux /usr/local/bin/portfolio-cli 

# Verify installation:
portfolio-cli
```
---

### 2. Install (Windows)

1. Download portfolio-cli.exe

2. Move it to a folder such as:
```text
C:\portfolio-cli\
```
3. Add that folder to your System PATH
4. Then run in terminal:

```text
portfolio-cli.exe
```
